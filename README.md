# AI-Based Detection and Classification of Industrial Fires and Persistent Thermal Sources Using NASA FIRMS, OSM & Satellite Data

**SIH Problem ID:** SIH26162  
**Organization:** National Technical Research Organisation (NTRO)  
**Category:** Software  

---

## 1. Problem Overview

NASA's Fire Information for Resource Management System (FIRMS) provides near-real-time thermal anomaly and hotspot data detected by satellite sensors (such as MODIS and VIIRS). While raw FIRMS hotspot data effectively identifies thermal anomalies globally, it does not natively distinguish between different sources of thermal activity. Specifically, thermal hotspots generated by:
- **Industrial activities** (e.g., refinery flares, cement kilns, steel mills, power plants, gas flaring)
- **Persistent / static thermal sources** (e.g., industrial heat emission sites, active slag heaps)

are often conflated with natural or surface thermal events such as vegetation, forest, agricultural stubble, or landfill fires.

Accurate, automated semantic classification of these thermal sources is vital for strategic intelligence, environmental monitoring, safety compliance, and industrial surveillance.

---

## 2. Project Objective

The goal of project **SIH26162** is to build an AI-driven geospatial intelligence platform that ingests thermal hotspot detection data from NASA FIRMS, enriches it with geospatial infrastructure context from OpenStreetMap (OSM) and auxiliary satellite data, and applies machine learning algorithms to accurately classify thermal anomalies into distinct categories—with a primary focus on isolating **industrial fires** and **persistent thermal sources**.

### Multi-Signal Classification Strategy
The eventual classification framework aims to integrate multiple complementary signals rather than relying on any single indicator:
- **FIRMS Thermal Attributes:** Brightness temperature, Fire Radiative Power (FRP), detection confidence, day/night flag, and satellite sensor type.
- **Temporal Persistence:** Historical recurrence and temporal frequency of thermal detections at specific geographic coordinates over extended observation windows.
- **Spatial Context & Infrastructure Proximity:** Proximity to OSM industrial zones, factories, refineries, power stations, chemical plants, and land-use tags. *(Note: Proximity alone does not confirm an industrial fire and must be evaluated alongside thermal and temporal traits).*
- **Spatial Clustering:** Spatial density analysis (e.g., DBSCAN or grid aggregation) to detect localized cluster patterns.
- **Environmental & Satellite Context:** Land cover type, vegetation indices, elevation, and auxiliary satellite imagery features.

## 7. Local Setup Instructions

### Prerequisites
- Python 3.10 or higher installed on your local machine.
- Git installed.

### Setup Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/shiromanitripathi/SIH26162-Thermal-Intelligence.git
   cd SIH26162-Thermal-Intelligence
   ```

2. **Create a Virtual Environment:**
   ```bash
   python -m venv .venv
   ```

3. **Activate the Virtual Environment:**
   - **On Windows (PowerShell):**
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```
   - **On Windows (CMD):**
     ```cmd
     .\.venv\Scripts\activate.bat
     ```
   - **On macOS/Linux:**
     ```bash
     source .venv/bin/activate
     ```

4. **Install Dependencies:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. **Configure Environment Variables:**
   Copy `.env.example` to `.env` and fill in your API credentials:
   ```bash
   cp .env.example .env
   ```

## 10. Data Integrity & Research Principles

- **No Synthetic Fabrication:** All training datasets, ground truth labels, FIRMS observations, and OSM spatial tags must be derived from verified data sources. Fake or fabricated data will never be presented as real evidence.
- **Empirical Validation:** Model architectures will be evaluated using rigorous spatial-temporal cross-validation to prevent spatial autocorrelation leakage.
- **Reproducibility:** All data preprocessing and feature extraction workflows must be fully scriptable and reproducible from raw data.
